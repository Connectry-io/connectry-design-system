# MemoryCard

One thing the brain keeps, shown so the person can see it, trust it and change it.

## Structure

- **Head.** "Kept · date" as `label`, the state word right: Private, Shared, Passed down.
- **Fact.** 17px 500 `ink`, one sentence, as specific as the source.
- **Why.** A well labelled Why, the reason in 13px. Every memory carries its reason.
- **Meta.** From (the source and its date) and Seen by (Only you, or the circle and its size).
- **Controls.** Three text links in the foot: Source in `blue`, Change and Forget in
  `muted`. No destructive red, no confirm dialog.
- **Forgotten.** A wide panel that says exactly what was removed and from where, with Undo.

## Never

A memory without its source, a confidence score, a red delete button, "Are you sure", a memory
shown to someone outside its circle.
