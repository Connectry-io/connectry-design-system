# ListRow

The system's list. A 52px key column in `ink` with tabular numerals, the line in `body`, a
state word in `faint`, a hairline between rows, and `ground` on hover at `radius-doc`.

Lists are hairline rows, not cards. A card per row makes a page of boxes and the system does
not do that anywhere.

## The state column

Always a word: Done, Moved, Confirmed, Needs you, Live. Never a colour swatch, never a dot
alone, never red or green. `faint` is legible here because the column is short and
12px, and the row's meaning does not depend on it.

## Where it is used

Today on the dashboard, every application space, the credit of a built thing, and any table in
a product surface. Column counts are chosen so every row is full.
