# EmailSignature

A four-row table, because mail clients do not lay anything else out reliably. No flexbox, no
grid, no background images, no web fonts: Inter with the system stack behind it.

Anatomy: the mark at 28px in a fixed 36px column, then the name at 15px weight 500 in `ink`,
the role at 13px in `muted`, a hairline, and the domain as the one link in `blue`.

The mark ships as a **hosted PNG at 2x**, not an inline SVG and not an attachment: an
attachment shows as a paperclip on every reply. Hosting for that PNG is an open question in
Governance.

Nothing else: no phone number block, no social icons, no quotation, no legal footer, no
"sent from", no meeting-booking link, no banner image.
