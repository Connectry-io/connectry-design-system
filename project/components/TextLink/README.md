# TextLink

`ink` with a hairline underline at rest, `blue` on hover with the underline taking the link
colour. Inside a sentence a link may be `blue` with no underline.

`blue` on `surface` is 5.1:1 and on `ground` 4.7:1, so a link is 15px or larger wherever it
carries the accent colour.

A link counts against the surface's blue budget: one primary action and one accent word or
link, at most twice per surface.
