# Footer

> Reference. The website uses **WebFooter**.

The lockup, one line, two links. That is the whole footer.

The line is "We run ours on it first.", the one claim the brand makes about itself, and the
only place "we" is the subject.

Two links at most: Privacy and Contact. No sitemap columns, no newsletter field, no social row,
no "made with", no copyright paragraph, no pricing link. A hairline above, `space-12` of air.
