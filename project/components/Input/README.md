# Input

A `surface` field with a hairline border `rgba(0,0,0,.12)`, `radius-card`, 12 by 14 padding,
15px text. The label sits above in 12px caps `faint`; the placeholder is `faint` too. Focus
draws the ring outside the field and darkens the border slightly.

## Errors

An error is a plain sentence beneath the field in `muted`. There is no red in this system and
no error colour: the sentence says what happened and what to do. The same slot carries help
text.

## Copy

The label names the thing, not the action. The placeholder is an example, never an
instruction, and the ask bar has no placeholder at all.
