# Chip

13px, 6 by 12 padding, `radius-pill`. A chip labels a state or carries the slogan; it is not a
button.

On `surface` or `ground` the chip is `ground` with a hairline. Selected fills `blue-tint` with
`blue` text. The dot, where a chip carries one, is 6px of `blue`.

On photography the chip is the glass material, so it needs the `#lens` filter and a picture
behind it. The social cards use exactly one glass chip, bottom right, carrying the slogan.

The state a chip shows is always a word. Colour never carries it alone.
