# ShareToCircle

The moment something moves from one person's memory into a circle. It is always a choice, always
shown, always reversible.

## Structure

- **Head.** `label` Share, the default state on the right: "Only you, until you choose".
- **The thing.** A doc preview: what it is, when it was built.
- **Circles.** One row per circle: a member circle, the name in 15px 500, who is in it in `muted`,
  a Toggle. Off by default.
- **The promise.** A well: "Mail is never shared. Nor is anything you have not picked here."
- **Actions.** Two pills, right aligned: the ghost "Keep it mine" and the one blue action, which
  names the circle ("Share with Lisbon").
- **After.** A panel saying what happened and who has it now, the members row, and Undo when
  it was taken back.

## Never

Sharing on by default, "share with everyone", sharing mail, a circle that shows a member's
private memory.
