# WebChaptersLight

The light edition of the same website: identical chapters, films, copy and components, with the pages between the films on the grey `ground`. Not a toggle on the site; a known version to build from when a surface needs light.

- Plain pages on `ground` `#f5f5f7`, type in `ink`, `body` and `muted`; `blue` for the one accent.
- Film chapters keep white type over the picture, exactly as in the dark edition.
- Films keep a clean edge on the grey ground: no fade into the page. The footer sits on the ground below the last film. On phones the words sit on the ground under each film, in ink, and the sources take light glass.
- Nav and menu use light glass (**WebNav**), the footer the light line (**WebFooter**).

Use the dark edition (**WebChaptersDark**) for the website. Use this one when a page lives beside light surfaces: a product page, a help centre, a partner page.
