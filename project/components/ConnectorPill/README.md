# ConnectorPill

A pill per connected tool: the product's **real mark** at 20px, its name, and a 34 by 20
toggle. The row ends with "Nothing to set up" in `muted`, pushed right.

The marks in the film are Gmail, Google Calendar, Google Drive, WhatsApp, Monzo, Strava and
Duolingo, each as its own mark, Connectry last in a host's list. A generic icon standing in
for a real product is on the never list: it reads as a mockup and undoes the claim the row is
making.

This system ships no third-party marks; fetch each from the vendor's own brand page and keep
it unmodified. Do not recolour a vendor mark to fit the palette.

The toggle is the one blue, on or off, with the state also written wherever the row is not
self-evident. No assistant or vendor is named in copy: the row shows marks, the words say
"wherever you already work".
