# DocPreview

A `surface` card at `radius-doc` with `shadow-doc`: a 9px caps label, a 14px title, and two
hairline rows standing for the body.

It says **something was built**. It is not a button, it has no button inside it, and it does
not open anything in a still. Inside a message panel it is the proof that the brain did the
work; inside a legacy panel it is the thing the circle kept.

Padding is `space-4` inside the panel around it. Two rows is the whole abstraction: a third
row starts to look like a document viewer, which this is not.
