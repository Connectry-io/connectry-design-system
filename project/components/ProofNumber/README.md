# ProofNumber

A hairline above, the figure at 28 to 40px in weight 500 with tabular numerals, the label
beneath in `muted`.

The proof row is three of these across, and the grid is chosen so the row is full.

## What may be a number here

164 consecutive daily briefings · 1,715 audited calls by four people · built for a team of 25.

Only numbers we can stand behind, and only ones about what we built and run. Never user
counts, revenue, pricing, "trusted by", or a compliance or certification claim. If a number
needs a footnote to be true, it does not go on a surface.
