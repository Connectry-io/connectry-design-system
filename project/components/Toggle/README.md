# Toggle

44 by 26, `radius-pill`. Off is a hairline on `ground`; on is `blue`. The white knob carries
`shadow-knob` and travels 18px in 200ms on `cubic-bezier(.2,.7,.2,1)`.

The connector row on the dashboard uses the small variant, 34 by 20, with the same colours.

A toggle is never any colour but the one blue, and its state is always also a word beside it.
Give it `aria-pressed` and a label; the focus ring applies as everywhere.
