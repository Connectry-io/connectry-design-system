# ApplicationTile

One of the applications, ready to use. `radius-card`, white at 55 percent with a 70 percent
white rim, sitting on the dashboard's glass.

Each tile carries four things and no more: a live dot, the name at 20px, a state label in blue
caps at the top right corner, and one line of status at 16px.

**A tile without a status is never shipped.** The status is the whole point: it says the thing
is already running, not that it is available to set up.

The applications are Circle, Trip, Health, Learning and Money. "Application" is the public
word; "space" is the internal one. They are cut by what people share, never by data source.

The tiles are a two-by-two on the dashboard's right column and a single column below 640.
Nothing to set up appears at the end of the connector row, not on a tile.
