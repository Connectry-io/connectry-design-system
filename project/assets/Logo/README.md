# Logo

The outlined masters. Use these in production; do not redraw the mark or set the wordmark
live in a shipped surface.

| File | What | Ink |
|---|---|---|
| `connectry-lockup-horizontal-ink.svg` | the horizontal lockup, 674.88 by 145.51 | `#1a1a1a` |
| `connectry-lockup-horizontal-white.svg` | the same, for dark and photography | `#ffffff` |
| `connectry-mark-ink.svg` | the mark alone, 100 by 100 | `#1a1a1a` |
| `connectry-mark-white.svg` | the mark alone, white | `#ffffff` |
| `connectry-favicon.svg` | the mark on `blue`, rounded square, 64 by 64 | `#ffffff` on `#4a6fa5` |

Each file carries its ink as a literal fill, not `currentColor`. A blue lockup on `surface` or
`ground` is made by taking the ink master and changing the fill to `#4a6fa5`; there is no blue
master because blue-on-anything-else is not a colourway.

The app icon is the mark on `blue` as a rounded square, the avatar the same on a circle; both
are cut from the favicon.

Clear space is half the mark height on every side. Minimum size: lockup 96px or 24mm, mark
16px or 4mm.

Never stretch, rotate, outline, gradient, shadow, recolour beyond the three colourways, change
the gap, add a symbol, animate the mark alone, or place the logo inside glass.
